# Periodic v1.0

Android 15-compatible foundation for **Periodic**, an immersive periodic-table and atomic-structure learning app.

## Included in this foundation

- Animated oxygen-atom opening screen
- Electrons locked to their visible elliptical orbit paths
- Interactive periodic table with all 118 elements
- Matte metallic category colors
- Raised prism-style element tiles with bevel, depth, shadow, and moonlit highlights
- Pinch zoom, pan, twist rotation, momentum, and double-tap reset
- Space environment with stars, a nebula/star cluster, and Saturn
- Element detail exhibits for atoms, nuclei, protons, neutrons, electrons, and quarks
- Android 15 / API 35 configuration
- GitHub Actions workflow that produces `Periodic-v1-debug.apk`

## Build with GitHub Actions

1. Extract this ZIP.
2. Upload everything inside the `Periodic-v1-Android15` folder to the root of a new GitHub repository.
3. Open **Actions** and run **Build Periodic APK**.
4. Download the `Periodic-v1-debug-apk` artifact.
5. Extract the artifact and install `Periodic-v1-debug.apk`.
